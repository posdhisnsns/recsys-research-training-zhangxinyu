# LDAS-8 实验分析与后续优化方向

分析日期：2026-10-26。最新完整实验：`20261026-145232-dynamic`，SASRec / Beauty / seed 2026，架构版本 18。以下把日志事实、只读诊断和待检验假设分别说明。本次没有修改训练实现、更新模型权重或启动新的完整训练。

后续实现说明：同日已按用户要求将两种训练模式合并为版本 19 的统一流程，启动命令与现行配置见项目 `README-8.md`。本文的模式分析、数值和待验证结论均对应合并前的版本 18 历史实验。

## 1. 当前结论

现有证据显示：增强器学会了大量选择尾部候选并显著减少教师预测扰动，但还没有证据证明这些编辑提高了尾部推荐的泛化能力。最先需要解决的是实验配置和可比性，然后是增强收益与实际尾部学习目标之间的连接。

**本次完整实验并不是默认四项优化的完整方案。** 命令明确指定 `--policy_learning=joint`，144 轮的 `proposal_updates` 总计为 0。按照 `components/trainers.py` 的实现，只有 `utility` 模式接入训练内部留出样本上的相对提案监督；`joint` 额外使用几何选择约束。因此不能据这次结果宣布“相对提案学习已经失败”或“四项优化均无效”。

本次每轮仍划出 13,701 个策略用户前缀，骨干微调使用 117,712 个前缀。统一划分有利于当前版本的受控比较，但在本次 joint 模式下，这批留出前缀没有用于提案监督；历史 none 实验没有相同的留出设置。

## 2. 实验结果与比较边界

全部取各运行最终测试记录，按验证集选择检查点。TADA 日志含后追加的评估记录，采用该检查点最后一次原始视图评估结果。

| 运行 | HIT@20 | NDCG@20 | Head NDCG@20 | Tail NDCG@20 | 尾部命中数@20 |
|---|---:|---:|---:|---:|---:|
| 历史 none，10-22 | 0.1016 | 0.0504 | 0.0764 | 0.0305 | 723 |
| 历史 dynamic joint，10-22 12:16 | 0.1029 | 0.0512 | 0.0778 | 0.0309 | 724 |
| 历史 TADA，10-22 | 0.1034 | 0.0513 | 0.0757 | 0.0326 | 752 |
| 最新 dynamic joint，10-26 | 0.1018 | 0.0499 | 0.0761 | 0.0299 | 711 |

数值上，最新运行较历史 TADA 的总体 NDCG@20 低 2.73%，尾部 NDCG@20 低 8.28%，头部高 0.53%；尾部少命中 41 个目标。较历史 none 的总体、尾部 NDCG@20 分别低约 0.99%、1.97%。这些是历史参考差值，**不是相同实验协议下的优化效应，也没有统计显著性结论**。

原因：除用户留出之外，动作空间、候选池、约束、辅助损失和学习路径均发生变化。全部只有一个种子，不能把不同时间的单次运行当作随机重复。

最新运行完成 144 轮，最佳验证轮次为 134。最佳验证 NDCG@20 为 0.0622，测试为 0.0499。二者来自不同时间目标，不能直接把差距解释成增强器过拟合；历史 none 也有相近的验证/测试差距。另外，日志里的 `baseline_validation_metrics=0.0501` 是预训练权重的验证成绩，不能与最新测试成绩直接相减。

最新训练阶段为 3,366.8 秒、总墙钟 3,472.9 秒，峰值已分配显存约 981 MiB。历史 none 的训练阶段为 485.9 秒，约相差 6.93 倍；该比值也受版本和配方差异影响，不是当前匹配条件下的额外开销测量。TADA 最后追加评估记录里的 0 秒训练时间不能当作它的训练成本。

### 3.2 只读检查点探针：安全不等于有助于学习

在最佳检查点上均匀抽取固定 2,048 个训练前缀，使用 float32，关闭骨干/教师 dropout，保留训练式随机编辑；没有反向传播或权重更新。使用与训练相同的 100 个推荐负例采样方式。这是训练前缀机制检查，不是新验证/测试结果。

| 诊断量 | 已学习策略 |
|---|---:|
| 实际编辑数 / 编辑率 | 1,494 / 72.95% |
| 编辑中插入占比 | 91.10% |
| 插入中末尾追加占比 | 0% |
| 新加入物品属于尾部的比例 | 92.03% |
| 编辑样本原始 / 编辑后序列尾部比例 | 39.84% / 51.54% |
| 编辑样本教师 JS 均值 / 中位数 | 0.001192 / 0.00000960 |
| 编辑样本教师 JS 第 99 百分位 | 0.02870 |
| 编辑样本满足 JS ≤ 0.02 的比例 | 98.39% |
| 编辑后学生 CE − 原始学生 CE | +0.00807 |
| 编辑后教师 CE − 原始教师 CE | +0.01036 |
| 学生 CE 改善的编辑比例 | 47.59% |

解释：策略在固定参考空间中倾向于加入尾部物品，并避开直接改变最后事件的追加动作；这些现象与低预测扰动一致。但是输入尾部比例变高没有转化为已确认的尾部测试收益。低平均 JS 也不能保证每一个编辑都在预算内。

不能仅因平均 CE 略升就断言增强无效：适度困难样本可能改善泛化。真正缺少的是“该编辑能否让学生更新后，在独立训练内部留出目标上变好”的测量。也不能仅凭约 91% 插入断言动作塌缩：当前长度不足 5 的前缀没有替换资格，需要在相同合法动作集合内分析。

另保存了随机策略探针，其平均 JS 和 CE 损害更高，但编辑率、位置分布和通过率均未匹配。它只能提供机制参考，不能代替等编辑率/等漂移的随机基线。

### 3.3 前缀和目标分布值得优先处理

直接从相同 Beauty 数据文件重算：

| 量 | 训练前缀 | 验证目标 | 测试目标 |
|---|---:|---:|---:|
| 样本数 | 131,413 | 22,363 | 22,363 |
| 输入长度 ≤ 3 的比例 | 45.60% | 32.03% | 0% |
| 尾部目标比例 | 39.00% | 50.15% | 56.72% |

另有 53.96% 训练前缀长度 ≤ 4，尚无替换资格。全长度训练前缀仅占约 2.68%，因此“满长插入丢最早行为”并非当前 Beauty 的主要场景。

这些差异来自所有训练前缀展开、留后目标及用户序列长度分布。它们提示需要按用户、长度、目标频次分组诊断，不直接证明前缀展开有害。后续不能利用测试标签比例反向设训练权重；应从训练内部按用户构造较晚前缀目标来估计所需的学习信号。

## 5. 优化方向及执行顺序

### P0：先检验完整 utility 路径与当前版本控制组

第一轮固定相同数据、预训练权重、微调用户划分、种子、负例、调参和早停规则，比较 `none / random / tada / dynamic-utility`。当前 joint 只作为额外消融。启动时明确记录提案监督是否启用，运行时核验 `proposal_updates > 0`、有效提案比例和监督梯度。

随机策略应使用相同动作、候选和门控；在验证集匹配实际编辑率，并报告漂移分布/通过率，必要时另做等漂移比较。不能把更低编辑率的随机探针当作严格对照。

对“划出 10% 用户是否抵消收益”增加一个独立对照：无提案的全量微调 vs 无提案的相同留出微调，保持其余设置一致。它测量数据利用差异，不改变主比较的划分。

通过标准：完整 utility 在验证集上改善总体或尾部表现，并且优势超过匹配随机策略；否则暂不叠加更复杂增强网络。已有的尾部提案目标加权在本次 joint 未启用，恢复它属于检验既有优化，不应包装成新方案。

### P1：按用户、长度和兴趣结构选择增强对象

根据 IERec 的选择性增强思路，结合本地 45.6% 的极短训练前缀，先做低成本实验：

1. 保留原始推荐分支的前缀训练；策略监督流按用户均匀抽样，并提高较晚训练前缀的占比，避免同一长用户的早期前缀主导策略学习。
2. 在相同增强样本总量下比较全量路由、长度分桶路由、长度条件下的兴趣熵/稳定性路由。每条历史计算路由时只使用当前可见前缀。
3. 极短序列允许插入/none，较长序列再考虑替换；对敏感样本保留 none。短序列兴趣熵估计不稳，先用长度桶和教师多视图一致性作回退，不机械照搬 IERec 的全局熵分位数。
4. 按长度桶报告头尾指标、编辑位置、接受率和更新后收益。若引入多偏好填充，只在训练视图实验，并用原始输入推理重新验证；不能直接引用 MuPP 原方案成绩作为等价结果。

这是分布和样本选择假设，不预设“短序列全部不增强”或“某一熵区间一定有益”。

### P1：收益目标对准学生更新后的尾部学习

先评估已有 utility 的教师即时评分；若其提案排序与真实下游收益相关性弱，再借鉴 MCLRec 的更新后反馈，而不是增加插入数量。

记不增强的一步更新为 θ′none，使用候选编辑的一步更新为 θ′a，在独立的训练内部策略样本上定义：

`U(a) = L_tail(θ′none) − L_tail(θ′a) − β · max(0, L_head(θ′a) − L_head(θ′none) − δ)`

该式奖励学生更新后的尾部改善，并对超过容许值 δ 的头部损害扣分；none 提供相同原始学习步骤的基线。它是本报告提出的待验证目标，不是 MCLRec 或现有 LDAS-8 的原公式。

先在少量提案上计算真实一步更新收益作为诊断，再评估便宜的梯度内积近似是否保留提案排序；确认相关性后才用于大规模训练。全模型二阶元梯度成本较高，不作为第一步。

排序目标可从“100 个均匀负例上的 CE”扩展到适量难负例上的平滑排名/间隔目标，核对其与全排序尾部 NDCG 的一致性。应让对照获得同样的负例信息和计算预算。不能仅通过增加新方法的负例数量制造优势。

原始 CE 全程保留。若 utility 的归一化教师增益大量达到截断上下界或因极小基准 CE 失真，应先记录基准损失和 reward 饱和比例，再考虑稳定的差值/排名信号；这目前是待检查风险，并非已证实的退化原因。

### P2：用分组风险约束服务长尾学习，避免只追求更低 JS

本次后期 active JS 已远低于 0.02，盲目收紧预算缺乏证据。结合 AsarRec 的信息性目标和 TADA 的长尾任务定义，建议：

- 同时记录头部/尾部目标、不同长度桶的 active JS、95/99 分位数、超预算率，以及更新后收益。全 batch 均值、active 均值和逐样本约束是三种不同保证。
- 使用兴趣/长度条件预算或分位数风险控制作为消融；预算只能依据训练内部/验证信息选择，不能用测试成绩设定。
- 将教师置信度校准、温度化 JS、头尾分层支持集或局部排序一致性作为待测方案。冻结教师可能继承流行度偏向，但本次日志没有证明教师偏差就是退化根因。
- 对少数兴趣/尾部排序的允许变化与真实意图破坏作区分；不要把原始教师全部预测概率都当作必须复制的事实。仍保留头部非劣性约束，避免以头部明显退化换取尾部数字。
- 只有训练内部目标能够支持有益性时才提高增强权重。固定均匀地加大尾部候选比例或叠加更多辅助损失不是当前优先方向。

## 6. 实验顺序与保留标准

| 阶段 | 改动 | 主要回答的问题 |
|---|---|---|
| A | 当前版本四组控制 + joint 消融 | 完整实现是否有效？策略是否优于匹配随机？ |
| B | 仅修改策略流的用户/末端前缀采样；随后单独测试样本路由 | 数据分布和增强对象是否是瓶颈？ |
| C | 一步更新收益诊断、教师收益相关性；随后单独接入近似收益 | 低漂移编辑是否确实帮助学生学习尾部？ |
| D | 在有效版本上加入分组/分位数风险约束 | 能否提高尾部收益，同时控制头部代价和少数高风险编辑？ |

先以一个种子做机制筛查，配置选择只看验证结果；通过后至少 3 个、优先 5 个种子，并扩展 Beauty / Sports / Toys。单种子筛查不是效果证明。对每一阶段报告总体与头尾 HR/NDCG、分长度指标、配对差值和计算成本；尽可能记录用户级结果以计算配对置信区间。后续独立改动不能同时改变骨干目标、候选池和训练数据，避免重新失去归因能力。

推荐的研究问题是：**如何选择在风险可控的前提下，真正改善尾部学习的离散序列编辑？** 当前日志已经提供了“尾部输入变多、预测几乎不变，但尾部目标未获益”的有价值负面案例；能否形成论文贡献仍取决于严格控制实验能否验证上述连接。
