# 可学习增强器（位置 + 类型）选题评估与实现方案

> 评估日期：2026-10-23
> 评估对象：序列推荐中"可自监督学习增强位置与增强类型"的增强器，目标是在尽量维持原序列语义的前提下引入长尾物品与多样性物品
> 依据：本项目 `knowledge_base/paper_reading` 已读的 TCLA / AsarRec / ACLSRec / TADA / BASRec / AdaTTA / MCLRec / IERec，以及 `experiment/TADA` 与 `experiment/ADARec` 现有代码
> 一句话结论：方向对，但**按现在的表述不能立题**。需要把贡献从"学位置和类型"搬到"学语义预算"，并先用一个诊断实验证明位置是主变量。

---

## 一、结论先行

1. **"可学习增强器"本身在 2025–2026 已经饱和。** TCLA（SIGIR'25）逐位置学 keep/delete/insert，并用"随机破坏→恢复"自监督预训练增强器；AsarRec（SIGIR'26）用独立增强器学生成矩阵并交替对抗优化；ACLSRec（WWW'26）用可学习扰动 + 恢复网络保语义；AdaTTA 用 PPO 按序列选增强类型。**"学位置 + 学类型 + 自监督"三个词连起来，基本就是 TCLA 的摘要。**
2. **"长尾 / 多样性"也已被占。** TADA（WWW'26）做头→尾替换与尾前插入；BASRec（AAAI'25）用跨序列 mixup 换多样性；SADA、DiQDiff 从生成侧解长尾与流行度偏置。
3. **真正空着的是两者之间的冲突没有被量化**：没有人回答"一条序列最多能注入多少尾部信号、注入在哪个位置，才不至于把下一次意图改掉"。TADA 用固定率 + 随机位置绕开了这个问题（靠表示层 mix 兜底）；ACLSRec 保语义但不注入尾部；TCLA 学位置但目标是"少改"。**这个空位可以立题，而且正好是现有 TADA 代码能低成本验证的。**

如果这是课程作业或开题，按原表述足够；如果要投 CCF-A，必须按第四、六节收窄。

## 三、四个必须先回答的问题

### 3.1 "自监督"监督什么：重构与尾部注入在目标上互相矛盾

TCLA 的自监督是"随机破坏 → 恢复原序列"。这个目标的最优解是**恒等映射**：什么都不改，恢复概率最高。用它训出来的位置选择器，天然倾向"少改、改在容易恢复的位置"。而尾部注入要求"改出一个原序列里没有的物品"，**不可恢复**。于是：

- 沿用重构目标 → 增强器会学会"不要插入尾物品"，与你的目的直接相反；
- 改成推荐损失驱动 → 就不是自监督，是监督 / 双层优化，2026 年的审稿人会抓这个词。

**建议**：把"自监督"限定在**位置**上。位置的价值可以由序列自身的扰动测出来（4.2 的 $c_t$），标签不来自推荐标签，这部分叫自监督是站得住的；类型与候选的选择用推荐目标 + 预算约束训练，正文不要称 SSL。

### 3.2 "维持语义"目前不可证伪

现有论文里的"保持语义一致"都是定性描述。审稿人一定会问：**怎么测？** 没有数，就无法证明"我的增强比 TADA 更保语义"，也无法证明长尾增益不是靠牺牲头部换来的。必须给出一个可计算定义（4.3 的 $D_H$），并且**训练用的漂移量与评测用的漂移量要分开**，否则是自证。

### 3.3 位置到底重不重要：这是整个 idea 的地基

SASRec 的下一项预测主要由最后几个位置决定。把第 2 个位置的头物品换成尾物品，和把倒数第 2 个换掉，语义代价完全不同。但 TADA 的实现（`experiment/TADA/src/datasets.py:203-219`）是**逐 token 独立伯努利、全序列共享一个 $p\sim U(a,b)$、候选随机取**，对"哪个头位置更便宜"没有任何概念。

如果实验证明"位置无关"，这个 idea 的地基就没了。**所以第一周先做诊断，不要先写模型。**

### 3.4 学习型策略有两个退化解

- **恒等**：不改，重构损失最低、推荐损失最稳；
- **全改**：只看尾部覆盖的话，策略会把每个位置都换掉。

必须同时具备：预算约束（软）、稀疏正则、以及**等漂移下比较**。否则学到的是"编辑率"而不是"编辑策略"。

## 四、推荐方案：BITE（Budgeted Influence-aware Tail Editing）

一句话：**把"增强多少"从超参变成一个可微的语义预算，让增强器学"在预算内把编辑放在语义代价最低的位置"。**

### 4.1 形式化

设 $S=[i_1,\dots,i_n]$，编码器 $f_\theta$，物品表 $E$，下一项分布 $p(\cdot\mid S)=\mathrm{softmax}(E f_\theta(S))$。头部集合 $\mathcal H$、尾部集合 $\mathcal T$ 由**训练集**频次划分。

增强器 $g_\phi$ 输出三件事：编辑位置 $A\subseteq[n]$、每个位置的操作 $o_t\in\{\textsc{sub},\textsc{ins}\}$、候选物品 $j_t$。增强序列 $\tilde S=\mathrm{Exec}(S,A,o,j)$。

### 4.2 where：语义价格（自监督部分）

$$c_t=D_{KL}\big(p(\cdot\mid S)\,\|\,p(\cdot\mid S_{\setminus t})\big)$$

$S_{\setminus t}$ 是把 $i_t$ 替换为 mask 的序列。$c_t$ 由两次前向得到，**标签来自序列本身，不用推荐标签**。

用一个小 MLP 学 $\hat c_t=\mathrm{MLP}([h_t; E_{i_t}; \mathrm{PE}_t; \mathrm{stats}])$，损失 $\mathrm{MSE}(\hat c_t,\ \mathrm{sg}(c_t))$。

含义：$c_t$ 是"动这个位置要付多少语义代价"。它可解释、可单独验证——画出来应该看到后段高、前段低、重复位置低。**这张图本身就是论文的动机图。**

### 4.3 what：受约束的动作空间

- **替换（sub）**：仅当头物品、且候选集非空；候选 $j\in\mathcal C_{\text{sub}}(i_t)\cap\mathcal T$，$\mathcal C_{\text{sub}}$ 复用 TADA 的 `head_combined`（共现 ∪ LIS）。
- **插入（ins）**：仅在尾物品位置前插入（沿用 TADA 的标签对齐技巧：$\tilde S$ 复制该尾物品，使 `target_pos/target_neg` 对齐），候选 $j\in\mathcal C_{\text{ins}}(i_t)\cap\mathcal T$，即 `tail_combined`。
- **类型头**：$q_t=\mathrm{softmax}(W_o h_t)$，按可用性 mask。
- **候选打分**：$s(j)=\cos(E_j,h_t)+\mu\log \mathrm{cooc}(i_t,j)$，softmax 采样（保留随机性，避免坍缩到单一尾物品）。

**语义保持有一半是动作空间给的硬约束，不是损失学的。** 这一点要写清楚，否则审稿人会以为全靠 $D_H$。

### 4.4 how much：语义预算

$$p_t=\sigma\big((\alpha\,\mathrm{tailaff}_t-\lambda\,\hat c_t)/\tau\big)$$

按 $p_t$ 做 Gumbel-top-$B$ 采样（无放回），$B$ 为每条序列的编辑预算。$\lambda$ 是语义价格：**训练时固定，推理时可扫描**——一个模型给出一整条 准确率–长尾–多样性 Pareto 前沿。这是相对 TADA 最直观的优势（TADA 每换一个 rate 都要重训）。

### 4.5 语义漂移的定义（关键支点）

$$D_H(S,\tilde S)=D_{KL}\big(p_H(\cdot\mid S)\,\|\,p_H(\cdot\mid \tilde S)\big),\qquad p_H(j)=\frac{p(j\mid S)}{\sum_{h\in\mathcal H}p(h\mid S)}$$

**只在头部子空间上算 KL**：尾部质量的移动不罚，头部排序的改变才罚。这一条把"注入长尾"和"保持语义"从对立变成可分离的两个坐标，是整个设计成立的前提。

### 4.6 总损失

$$\mathcal L=\mathcal L_{rec}(S)+\alpha\mathcal L_{rec}(\tilde S)+\beta D_H(S,\tilde S)+\gamma\mathcal L_{tail}+\delta\mathcal L_{div}+\eta\big(\textstyle\sum_t p_t-B\big)_+^2+\zeta\sum_t p_t$$

| 项 | 作用 | 去掉会怎样 |
|---|---|---|
| $\mathcal L_{rec}(\tilde S)$ | 增强视图仍预测原始下一项（标签对齐），最强的语义锚 | 长尾注入变标签噪声 |
| $D_H$ | 只罚头部漂移 | 头部指标掉 |
| $\mathcal L_{tail}=-\log\sum_{j\in\mathcal T}p(j\mid\tilde S)$ | 让增强视图的预测质量向尾部移动 | 只剩随机噪声 |
| $\mathcal L_{div}$ | batch 内 top-K 类别熵 / ILD（次要项，权重小） | 多样性主张弱 |
| 预算项 + L1 | 防止"全改" | 策略退化为编辑率 |

注意 $\mathcal L_{tail}$ 作用在**训练视图**上，不是让模型在推理时多推尾物品——这个区分要在正文里反复强调，否则会被当成 popularity debias。

### 4.7 训练流程

```
for each batch:
  S, y = batch                        # y = 原始下一项
  # 1) 语义价格（no_grad，每 batch 只采样 m 个位置）
  idx = sample_positions(S, m)
  c   = KL(p(S), p(mask(S, idx)))     # 两次前向，self-supervised 标签
  # 2) 增强器
  ĉ   = MLP(enc(S))[idx]              # 与 c 做 MSE，梯度只进 MLP
  p_t = σ((α·tailaff - λ·ĉ)/τ)
  A   = gumbel_topk(p_t, B)
  o   = type_head(S)[A]
  j   = candidate_score(S, A, o).sample()
  S̃   = exec(S, A, o, j)              # 复用 TADA 的 target 对齐
  # 3) 推荐器
  L = L_rec(S,y) + α L_rec(S̃,y) + β D_H + γ L_tail + δ L_div + η·budget + ζ·L1
  update θ, φ
```

### 4.8 与现有代码的对接

| 需要的东西 | 现成位置 |
|---|---|
| 头尾划分、共现候选集 | `experiment/TADA/src/ht_process.py::classify_head_and_tail`、`build_head_tail_relation`（已有 `head_combined` / `tail_combined`） |
| 算子入口 | `experiment/TADA/src/datasets.py::augment / substitute / insert`，只需把随机采样换成策略采样，四元组 `aug_1/aug_2/aug_pos/aug_neg` 签名不变 |
| Gumbel straight-through | `experiment/ADARec/ADARec-2/modules.py::gumbel_softmax`（9-13 已调通） |
| 骨干与评测 | TADA 的 `main.py` 全排序协议（切分必须与基线一致，注意 SSS 那个评测陷阱） |

### 4.9 成本与 8GB 可行性

- 增强器：1 层 Transformer，$d=64$，$L\le 50$，参数量 < 0.1M；
- 额外前向：语义价格每 batch 只算 $m$ 个位置（建议 $m=8$/序列，或全 batch 512 个位置槽），约 +30%~50% 训练时间；
- 推理：**零额外开销**，增强器只在训练期存在——这点比 AdaTTA 的 1.48× 好讲；
- 显存：SASRec $d=64$ / $B=256$ / $L=50$ 完全够。**不要在这条线上再叠扩散**（ADARec 的经验：`Tmax=10` 时逐层前向显存 5–10 倍）。

## 六、实验设计

### 6.1 设置

Beauty / Sports / Toys（TADA 已有预处理），SASRec 主骨干 + FMLPRec 副骨干，全排序，3–5 个种子。切分协议与 TADA 主实验完全一致，否则不可比。

### 6.2 指标

| 类别 | 指标 | 说明 |
|---|---|---|
| 准确率 | HR/NDCG@5,10,20 | 全排序，与 TADA 同协议 |
| 长尾 | TailRecall@K（在目标 $\in\mathcal T$ 的子集上）、TailCoverage、曝光 Gini | 必须分组报告，不能只报总体 |
| 多样性 | ILD@K、类别熵@K、Novelty | 次要主张，别过度声称 |
| 语义漂移 | 头部 KL $D_H$、Top-1 一致率、目标物品排名位移 | **评测用的漂移要与训练用的分开** |
| 成本 | 训练时长、显存、推理延迟 | 推理应 ≈ 基线 |

### 6.3 消融与对照

| 编号 | 配置 | 回答的问题 |
|---|---|---|
| A0 | SASRec | 基线 |
| A1 | TADA（固定率 + 随机位置） | 现有最强长尾基线 |
| A2 | 固定率 + **学习位置** | 位置单独贡献多少 |
| A3 | **学习率** + 随机位置 | 预算单独贡献多少 |
| A4 | BITE 完整 | — |
| A5 | A4 去掉 $D_H$ | 语义约束是否必要 |
| A6 | A4 去掉预算项 | 会不会退化成全改 |
| A7 | A4 去掉候选共现约束（任意尾物品） | 语义是否主要来自候选集 |

- 诊断阶段若"影响低位置"与"随机位置"在等漂移下的尾部增益差 < 1 个标准差（3 seeds）→ **位置不是主变量**，转 B 方案，或把主张改成"可控性"。

## 八、审稿人问题预演

| 问题 | 回答要点 |
|---|---|
| 与 TADA 的区别？ | TADA 固定率 + 随机位置，靠表示层 mix 兜底；我们在**等漂移**下比较，并证明位置是主变量；一个模型给出一条前沿，TADA 每个 rate 要重训。 |
| 与 TCLA 的区别？ | TCLA 学位置是为了**重构**（目标是最小改动、可恢复）；我们学位置是为了**在语义预算内最大化尾部暴露**，目标相反，重构会主动抑制尾部插入（3.1）。 |
| 与 AsarRec 的区别？ | AsarRec 学对抗性难视图、无长尾目标、用双线性匹配矩阵；我们用影响估计 + 预算约束，可解释、可单独验证、训练成本低一个量级。 |
| 自监督在哪？ | 只有语义价格 $\hat c_t$ 是自监督（标签由序列自身扰动产生）。其余部分不要称 SSL。 |
| 长尾提升是不是靠牺牲头部？ | 等漂移对照（A9）+ head/tail 分组指标。 |
| 为什么不直接用 popularity debias / rerank？ | 那些改推理分布；我们改训练分布，推理零开销。rerank 直接掉 NDCG，我们的目标是在等漂移下换尾部。 |
| 尾部定义敏感吗？ | 报告阈值（频次 ≤ 20 / 底部 80%）的敏感性。 |

## 九、风险清单

1. **数据泄漏**：尾部候选池可能包含该用户自己的未来物品。建池时必须排除用户验证/测试段，否则尾部指标虚高。
2. **候选集规模**：`head_combined` / `tail_combined` 是全局共现，可能很大；打分要限制在每个 anchor 的 top-M，否则无法向量化。
3. **尾部正样本太少**：TailRecall 的置信区间会很宽 → 用按用户 bootstrap 报告。
4. **数据集依赖**：位置敏感性与稀疏度强相关（Sports 比 Beauty 稀疏）。如果只在 Beauty 上有效，主张要收窄。
5. **"多样性"容易变成第二个指标战场**：建议只作次要主张，主打长尾。
6. **时间**：三个月做 A 方案偏紧，诊断阶段必须两周内出结论。
