## 1、最近学习内容

- **把“初版消融”和“严格消融”彻底分开了**。之前加的 `--ablate_adc` / `--ablate_hda` / `--ablate_moe` 其实是初版消融，问题很大：
    
    - 初版去 ADC：固定单深度 + 跳过 controller + `probs=None`，结果连带把 HDA 多深度分层压成单深度，`L_expl` 也归零。
        
    - 初版去 HDA：直接 `return raw, raw, probs`，adaptive 分支走不到 encoder，HP-MoE 也跟着失效。
        
    - 所以初版消融是“三个组件互相牵连”，测不出单个组件的贡献。
        
- **重写了严格消融**，加在官方原版代码 ADARec 上：
    
    - `ablate_adc`：用均匀权重 `probs = 1/K` 代替 controller，HDA 仍然遍历所有 `diffusion_levels` 并加噪，HP-MoE 融合完整，只把 `probs_for_return=None`，做到“只去自适应”。
        
    - `ablate_hda`：保留 for 循环多深度遍历，只把每层 `diffused_emb = E_0`，ADC 深度选择、encoder 前向、HP-MoE 融合都保留，做到“只去加噪”。
        
    - `ablate_moe`：保持设计意图，只训练/评测浅层专家 e5，深层专家 e10 退出。
        
- **严格消融 Beauty 结果**：
    
    - 完整模型 Beauty-1：HR@5 0.0587 / NDCG@5 0.0392 / HR@20 0.1169 / NDCG@20 0.0557。
        
    - 严格去 ADC（Beauty-7）：0.0580 / 0.0393 / 0.1168 / 0.0559，NDCG@20 几乎不降，甚至微升，**没有复现论文 w/o ADC 的 -4.1%**。
        
    - 严格去 HDA（Beauty-8）：0.0568 / 0.0382 / 0.1158 / 0.0548，NDCG@20 下降约 1.6%，方向对，但远小于论文 -7.0%。
        
    - 严格去 MoE（Beauty-9）：单专家 e5，0.0575 / 0.0388 / 0.1144 / 0.0548，NDCG@20 下降约 1.6%，远小于论文 -11.1%。
        
    - 三消融全开（Beauty-10）：0.0598 / 0.0403 / 0.1193 / 0.0571。日志里 e5/e10 都训练且指标完全相同，说明组合开关下 `ablate_moe` 没走“跳过 e10”，而是走了“e5/e10 同配置”。由于双同配置专家等权平均等价于单专家，结果上可作为“去 ADC + 去 HDA + 去 HP-MoE”的有效三消融结果。
        
- **参数实验：代码默认参数 vs 论文参数**：
    
    - 官方原版代码默认参数就能完美复现论文：Beauty 0.0392 vs 论文 0.0403，Sports 0.0224 vs 0.0228，Toys 0.0474 vs 0.0474（Toys 完全一致）。
        
    - 把论文参数原样套进代码反而崩：Beauty-6 NDCG@5 从 0.0392 跌到 0.0151，Toys-1 / Toys-2 跌到 0.0052 / 0.0049，Toys-3 也只有 0.0182。
        
    - 崩溃边界不是单一因素：
        
        - Toys-5：`τ=1.0 / wd=0 / deno=0.1 / expl=0.01`，NDCG@5 0.0463，接近论文 0.0474，说明只改变$λ_{deno}$和$λ_{expl}$对结果影响较小， 具有一定鲁棒性，τ 过小才是是重要崩溃因素。
            
        - Toys-6：`τ=1.0 / deno=1e-4 / expl=1e-4`，但 `wd=1e-4`，NDCG@5 仍只有 0.0280，说明 `weight_decay=1e-4` 在 Toys 上单独就能导致崩溃。
            
- **稀疏序列复现**：
    
    - `--shorten_seq_to 5` 是正确写法，真正把用户历史截到最近 5 个物品；`--max_seq_length 5` 只是把张量长度限到 5，不做过滤。
        
    - Sports 稀疏：本地 H@5 0.0306 / N@5 0.0204，论文 0.0305 / 0.0199。
        
    - Yelp 稀疏：本地 H@5 0.0195 / N@5 0.0123，论文 0.0200 / 0.0124。
        
    - 稀疏场景基本复现成功。
        
- **阶段性结论**：
    
    - 严格消融后，去 ADC 不降，去 HDA / 去 MoE 只微降，仍远小于论文下降幅度。
        
    - 当前代码里能稳定复现的增益，主要来自 SASRec / ELCRec 骨干 + 双专家 ensemble；ADC / HDA / HP-MoE 的边际贡献被 ensemble 效应和语义偏差淹没。
        
    - 但不能直接说“论文模块无效”，因为官方原版代码对论文语义做了简化，且论文超参在本地会崩。

## 3、遇到的问题

- **严格去 ADC 后指标不降反微升**，没有复现论文 -4.1%。严格消融已经排除了初版“互相牵连”的问题，但结果仍说明：在官方原版代码实现下，ADC 的自适应空间太小。
    
- **去 HDA / 去 MoE 只降 1.6% 左右**，远小于论文 -7.0% / -11.1%。双专家 ensemble 本身是强 baseline，会掩盖单模块边际贡献。
    
- **论文参数“水土不服”**：Beauty -62%，Toys -89%。根因是代码里的去噪损失是“表示重构 MSE”，论文是“噪声预测 MSE”，方向不同；探索损失权重语义也不一致。
    
- **Beauty-10 的 `ablate_moe` 实现路径不一致**：名义三消融全开，但 e5/e10 都训练且指标完全相同，没走“跳过 e10”路径。结果等价单专家，可以作为三消融有效结果，但要在笔记里注明实现差异。
    
- **崩溃边界复杂**：τ 过小、`weight_decay=1e-4`、`deno/expl` 语义不匹配共同作用，不能只归因于某一个超参。
