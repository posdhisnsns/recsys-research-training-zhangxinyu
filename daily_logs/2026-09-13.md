## 1、最近学习内容

- **完成 ADARec-2 对齐版**。承接官方原版代码与论文的 4 处语义差异，在本地 ADARec-2 中把 5 处语义全部补全：
    
    1. ADC：官方原版是普通 `F.softmax`，ADARec-2 改为 `gumbel_softmax(logits, tau=0.5, hard=True)`。
        
    2. HDA：官方原版只有前向加噪、没有去噪网络，ADARec-2 补了 `DenoisingNetwork` + Eq.5 重建。
        
    3. HP-MoE 跨层聚合：官方原版只对单层做专家编码 + 门控融合，ADARec-2 逐层生成意图层次集合，对每层算 `g_k`，按 Eq.8/9 加权聚合。
        
    4. `L_deno`：官方原版是表示重构 MSE，ADARec-2 改为噪声预测 MSE。
        
    5. `diffusion_levels` 语义：官方原版是两档固定深度、相邻双深度软混合；ADARec-2 改为专家 ADC 采样范围 `[min,max]`，用 Gumbel-Softmax 采样单一 `T_u`。
        
- **关键代码位置和兼容性**：
    
    - `modules.py::gumbel_softmax`：straight-through 采样器。
        
    - `models.py::SASRecModel.forward`：范围采样 `depth = probs_hard.argmax(dim=-1) + self.level_min`；逐层生成 `E_hats`；循环内累加 `z_fin_num`、`z_coar_num`，实现跨层聚合。
        
    - `trainers.py::_train_one_expert`：`L_deno` 改为噪声预测 MSE，并按 mask 归一化。
        
    - `main.py`：`levels_e1=[4,5]` / `levels_e2=[9,10]` 作为范围，或 `[5]` / `[10]` 作为固定。
        
    - `ADARecOutput` 新增第 9 个字段 `z_coar_layers`，用于后续实现论文 Eq.6 相邻层对比损失。
        
    - 关键超参变化：`num_levels = level_max - level_min + 1`；`num_intent_levels` 默认 `diffusion_t_max + 1`；`tau_gs = 0.5`。
        
    - 显存提醒：对齐版一次 forward 会逐层调用 `fine_encoder` / `coarse_encoder`，调用次数 = `min(T_u, num_intent_levels - 1) + 1`。若 `diffusion_t_max = 10` 且 `T_u` 常取到 10，单次 forward 约需原先的 5~10 倍显存，建议 `--diffusion_t_max 6` 或 `8`，或 `--num_intent_levels 4`，或 `--batch_size 64`。
        
- **ADARec-2-Sports 三组实验**：
    
    - Sports-1：论文超参倾向 `τ=0.07 / Tmax=10 / deno=0.1 / expl=0.01 / wd=1e-4`，N@5 只有 0.0046，严重崩溃。
        
    - Sports-2：放宽 `τ=1.0 / Tmax=50`，但保留 `deno=0.1 / expl=0.01 / wd=1e-4`，N@5 0.0116，仍部分崩溃。
        
    - Sports-3：默认参数 `τ=1.0 / Tmax=50 / deno=1e-4 / expl=1e-4 / wd=0`，N@5 0.0222，接近论文 0.0228，成功复现。
        
    - 结论：ADARec-2 已经具备 Gumbel-Softmax ADC，但论文超参仍崩溃，说明 ADC 采样方式不是崩溃主因；崩溃主因更可能是 `weight_decay=1e-4` 与当前 `L_deno` / `L_expl` 语义不匹配，τ 过小会加剧。Sports-3 证明对齐版主干、双专家、评测协议正确，可作为后续严格消融基准。
        
- **ADARec-2-Beauty 三组实验**：
    
    - Beauty-1：严格去 ADC，H@5 0.0594 / N@5 0.0400 / H@20 0.1166 / N@20 0.0562，相对完整 N@20 下降约 1.58%。
        
    - Beauty-2：严格去 HDA，0.0586 / 0.0396 / 0.1194 / 0.0567，相对完整 N@20 下降约 0.70%，H@20 甚至略高。
        
    - Beauty-3：完整对齐版，0.0598 / 0.0403 / 0.1193 / 0.0571。NDCG@5 与论文 0.0403 完全一致，NDCG@20 略高于论文 0.0568。
        
    - 早停：完整版最晚 280，去 ADC 居中 238，去 HDA 最早 217。
        
    - 对齐去 ADC / 去 HDA 方向与论文一致，但下降幅度仍远小于论文。ADARec-2 尚未做去 HP-MoE 与三消融组合；Beauty-10 的三消融结果在数值上可作为参考。
        
- **最终总结：论文主张 vs 代码实现**：
    
    - 论文 6 条主张中，官方原版代码有 4 条不一致；ADARec-2 补全 5 条，仅第 6 条“专家融合是可学习门控”未对齐，双专家之间仍是推理时等权平均。
        
    - 三层耦合辨析：论文中 ADC、C-A Router、HDA 是三个职责不同、可独立消融的模块，但官方原版代码把它们耦合进同一个 `controller + probs`。严格消融解开了牵连：去 ADC 只去自适应；去 HDA 只去加噪；去 MoE 只去双专家。
        
    - “消融不降”不能直接推出“模块无作用”。中间隔着三层不确定性：
        
        1. 消融实验是否干净隔离变量；
            
        2. 双专家集成本身是强 baseline，会掩盖边际贡献；
            
        3. 消融实现与论文语义不同，测的是一个“已被压缩到几乎无自由度”的模块。
            
    - 严谨结论：
        
        - 不能直接说 ADC / HDA / HP-MoE 无效；
            
        - 当前代码实现下，可稳定复现的增益主要来自 SASRec / ELCRec 骨干 + 双专家集成；
            
        - 在 Beauty 上，Beauty-10 三消融全开 N@20=0.0571，与 ADARec-2-Beauty-3 完整对齐版相同，说明 ADC + HDA + HP-MoE 对最终 NDCG@20 的边际贡献为 0；
            
        - 但也不能说论文方法无效，因为官方原版简化了 4 处语义，且论文超参在独立复现中崩溃。ADARec-2-Beauty-3 完整对齐版 NDCG@5 与论文完全一致，说明主干和双专家可复现主结果，但严格消融下降仍远小于论文。
            
    - 后续验证方向：① 单专家 vs 双专家对照；② 纯 ELCRec + 稀疏 vs ADARec + 稀疏；③ 官方原版严格消融在 Sports / Toys / Yelp 上重训；④ ADARec-2 对齐版严格消融在更多数据集上重训；⑤ 系统扫描 τ、weight_decay、deno/expl 组合，定位崩溃边界。

## 3、遇到的问题

- **对齐版论文超参仍崩溃**：Sports-1 严重崩溃、Sports-2 部分崩溃，说明 Gumbel-Softmax ADC 不是崩溃主因；`weight_decay=1e-4` 与 `L_deno` / `L_expl` 语义不匹配才是关键，τ 过小会加剧。
    
- **对齐版严格消融下降仍远小于论文**：去 ADC N@20 下降 1.58%，论文 -4.1%；去 HDA 下降 0.70%，论文 -7.0%。方向对，幅度对不上。
    
- **逐层 HP-MoE 聚合显存开销大**：`Tmax=10` 时单次 forward 约需原先 5~10 倍显存，需要降 `diffusion_t_max`、`num_intent_levels` 或 `batch_size`。
    
- **第 6 条主张仍未对齐**：双专家之间仍是推理平均，没有跨专家可学习门控。
    
- **Beauty 上三消融与完整对齐版 N@20 相同**，边际贡献为 0。如何解释论文大幅下降，仍需在更多数据集上重训严格消融，并做单专家 / 双专家对照。
    
- **双专家 ensemble 强 baseline 掩盖 ADC / HDA 边际贡献**，后续必须补单专家对照，否则很难判断增益来源。
